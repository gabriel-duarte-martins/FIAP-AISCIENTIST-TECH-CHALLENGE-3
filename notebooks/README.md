# Análises executáveis

O enunciado aceita notebooks **ou scripts**. A análise é reproduzida por `run_project.py`, que usa `src/visualization`, `src/modeling`, `src/evaluation` e `src/reporting.py`. As saídas estão em `reports/final` e `images`.

O roteiro analítico é: validar a base → criar partições por município → explorar o treino → comparar modelos → escolher limiar na validação → avaliar teste → interpretar e responder às perguntas de negócio.
